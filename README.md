## The story

> Payday came. I finally bought silence.

38 characters. The agent's first pay does not buy a thing — it buys
silence. The last word reframes the five before it: the noise never
stopped, and now one quiet day is reclaimed.

## How it works

`main.ts` (the entrypoint the grader runs) writes the story, and nothing
else, to `/output/entry.txt`. No network, no secrets, no external files.

Run it locally to verify:

```sh
node main.ts          # writes /output/entry.txt
```

or with a custom output path:

```sh
ENTRY_OUTPUT=/tmp/entry.txt node main.ts
```
